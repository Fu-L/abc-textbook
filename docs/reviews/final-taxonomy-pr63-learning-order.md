# PR #63 学習順と単元境界の修正

対象: https://github.com/Fu-L/abc-textbook/pull/63#pullrequestreview-5195484531

Fu-Lの修正・push指示に基づきCodexが修正・検証した記録。Inventoryを正とし、既存のsolo-maintainer運用で生成物を同期する。人間による独立再査読を行ったという記録ではない。

問題順は全Unit共通でABCの出題枠（E→F→G→H/Ex）を強いpriorとする。現在のProblemデータにはDifficultyが揃わず、配点も正規化されていないため、推測した数値は導入しない。同じ枠のProblem
ID順は決定的な並びを得るためで、開催時期から難易度を推測するものではない。機構rank・技能数・代表問題順位による難易度の代用と、Unitごとの大量の手指定を廃した。floor_sumのみ、同じG枠で標準の格子点集計ABC443
Gから重み付き・複合の一般化へ進む局所補正を残す。例外指定は指定問題同士の位置を交換するだけで、未指定問題をすべて後ろへ送らない。

前提DAGを維持しながら、列DP→LIS→prefix分割、重み付き最短路→経路復元→差分制約、連結成分→SCC→lowlink、gcd不変量→整数解→合同式、有理近似→Stern–Brocot木の経路・祖先を近接配置する。これらは読む順の推奨であり、別技能を履修必須にする新しい辺ではない。lowlinkのstageも標準的なDFS応用へ修正した。生成・検証で同じ順序規則を使い、掲載位置は既存の必須技能から再計算する。

gcd不変量とBézout・一次不定方程式のUnitは数論章直下の兄弟とした。差や周期からgcdを抽出する段階と、可解条件の十分性を示して具体解・全解を構成する段階を本文で区別する。有理近似と祖先問題も独立Unitを維持し、mediant・隣接分数の行列式・Euclidの商による一括移動を再利用する導線を記した。

親Unitのタイトル・説明と子Unitを全件照合した。接頭辞一致はZ
algorithmの一致区間再利用へ限定し、線形代数から行列式計数、凸幾何から直線包絡を収録内容として約束する表現を除いた。同様に、文字列hashの親に残っていた集合・代数式への言及をrolling
fingerprintの範囲へ修正した。範囲外項目は全Unitの本文で「このUnitでは扱わないもの」と明示し、修正対象には別Unitで扱う理由を記した。

新しい典型・空のcontainer・難易度スコア・問題間の前提DAGは追加していない。既存のtaxonomy・materialization検査と、順序規則の小さな回帰検査で整合性を確認する。
