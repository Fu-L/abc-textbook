# Inventory起点・semantic placement全868問の最終再監査

## 結論

Technique Inventoryを真として実施された2回の全件手動意味監査（各868問）の判断を、現行placementへ再突合した。現行データに未修正の分類誤りは認めなかった。過去の監査で計25問に誤りを見つけ、現在のplacementでは全25件が修正されている。残る843問は監査時から修正を要する根拠がなかった。

この一覧のPはsemantic primary、Cはco-primaryが存在する場合のhome選択、Sはsupportingの必要十分性を表す。`—`はその問題にco-primaryがなく、home選択を判定しないことを示す。`○`は現在の分類が意味上整合することを示す。履歴欄にある誤りはすべて修正済みで、現行の誤りを意味しない。

元の分類判断はInventoryの採用・棄却案、観察、key insight、algorithm connection、typical technique、prerequisiteを読んで意味的に行われている。今回の最終突合では、InventoryとplacementのID集合が868件で一致すること、および25件の修正が現行データへ反映済みであることを確認した。自動処理はID網羅性の照合と人手で確定した結果の表形式への転記だけに使った。一般的な算術・heap操作の網羅はsupportingの基準とせず、独立に学ぶ必要がある技術を対象にした。
