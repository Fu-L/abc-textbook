## 根本原因

典型手法の名称と大まかな式だけでは、問題文の量化範囲、変換の必要十分条件、再帰内での回答の保存時点、最終出力までの接続が欠けたままになっていた。本文とClaimの一致や構造検査も、同じ誤解を両方に書けば検出できない。

本文を「元の条件→状態の意味→初期値と具体的な遷移→答え→実行順に沿った計算量」までつなぎ直した。学習成果と前提関係は維持し、ARC・AGC・CF
Div.
1・UCUPへ持ち出す際にも再現できる説明にする。執筆手順の[問題条件から回答への接続](../../operations/problem-shards.md#問題条件から回答への接続)にも今回の点検項目を反映した。
