対象: <https://github.com/Fu-L/abc-textbook/pull/65#pullrequestreview-5404957719>

全868問（DP174、グラフ・探索172、データ構造94、数学147、文字列・幾何79、複合202）の考察・正当性・計算量の要点を横断点検した。全本文から照会範囲、整数境界、寸法と初期化、最短距離の基底を抽出し、同じ原因が疑われる本文と前提単元を詳細に確認した。指摘3問を含む12問と5単元を補修した。全件の記述点検、補修箇所の一般証明、有限モデルとの比較、全本文の構造同期は別の検査であり、全868問を独立に証明し直したという記録ではない。

## 根本原因と修正

抽象的な要約・永続化・slope
trickの説明から、問題固有の照会集合・寸法・整数domainへ戻す接続が抜けていた。更新を正しく集約できても、全体最大値と指定区間の最大値は異なる。版の数と一版の長さも異なる。凹性を保つ実数の更新でも、毎日の人数と余りを整数で保持しなければ元のDPにはならない。

関連単元のrange-actions、persistence、slope-trick、isotonic-regression、line-envelopeに、それぞれ照会範囲、構造共有による初期化、有限整数domain、整数blockの両端比較、符号付き切替整数を追加した。ARC・AGC・CF
Div.
1・UCUPの初見問題に転用する際に、既習の典型から問題の手順を再構成するための内容である。Outcomeと配置・前提関係を変更せず、[執筆手順](../../operations/problem-shards.md#照会する集合寸法整数domainを固定する)にも具体的な点検観点を追記した。
