## 根本原因

代表化や局所条件の結論を、初期状態・元の対象への逆写像・最適性の達成まで説明したものとして扱っていた。ABC446
Gでは空列の位置0と、存在しない0回目の出現位置が混同され、開区間から初期状態を除いていた。ABC302
Gでは閉路分解できるという事実だけで特定のpotentialを達成できると結論していた。解法名や分類名に前提の役割を背負わせても、その問題固有の境界・操作列・成立条件は補えない。

正準化の単位、番兵と空状態、閉区間・半開区間、下界と達成する操作列を分けて説明する。操作列では必要な資源と処理順を、計算量ではその具体的なループと生成数を数える。[執筆手順](../../operations/problem-shards.md#正準化の単位番兵下界の達成を点検する)へこの観点を追加した。教科書の配置・Outcome・前提体系は引き継ぎ、既存の正規化、交換論、DP遷移集約、区間分割管理の本文を補った。
