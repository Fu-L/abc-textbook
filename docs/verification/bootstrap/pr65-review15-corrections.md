# PR #65 第十五回レビューの本文補修

対象: <https://github.com/Fu-L/abc-textbook/pull/65#pullrequestreview-5404148632>

全868問を、DP174問、グラフ・探索172問、データ構造94問、数学147問、文字列・幾何79問、複合202問に分け、考察・正当性・計算量の一覧から点検した。局所変換をまとめる手順、走査省略の条件、交換の停止形、補助状態の初期値と更新順、構成の具体的な接続、等号入力と最後の復元式を確認し、疑義のある本文と共通Unitを詳細に読んだ。レビューの3問に加え、同種の説明不足が見つかった5問と共通3単元を補修した。

この横断点検と、補修対象の一般証明、小規模な独立モデルとの有限比較、全868問の本文・Claim同期は別の検査である。全868問を独立に証明し直したという記録ではない。

## 根本原因

既習の典型の名称や局所操作の合法性を、問題固有の高速化・構成手順の説明として扱っていた。ABC427
Gでは局所交換を繰り返すと二乗回数になり、二進ブロックの償却だけでは線形マージを導けない。ABC349
Gでは通常のManacherを既習としても、未知文字列の指定半径から制約を生成するskip条件と矛盾入力での仕事量は別途必要だった。ABC310
Exでは交換の合法性だけから、停止後の資源上界と短いコンボ分解までは導けなかった。

共通Unitにも、作用保存とcursorによる仕事量、条件付きの制約圧縮と無条件の計算量、資源を有限化してから密度交換へ進む順序を追記した。[執筆手順](../../operations/problem-shards.md#局所操作から総仕事量と停止形へ接続する)には、その問題固有の代入・不変量・停止量・停止形・終了処理まで本文から復元できることを点検基準として加えた。
