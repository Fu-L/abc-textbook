## 全問題解説集への整理

新しいコメントを優先し、Guide /
Transfer選定表、役割付きの例・評価課題の生成、Outcomeごとの評価課題のexactly-once検証を削除した。Tag
/ Outcomeは分類・前提・関連のmetadataとする。仕様・計画・作業定義も同じ方針へ更新した。

各ProblemのpresentationUnitIdを一意に保ち、directProblemIdsに読む順序を固定する。problemIdsは自身と子孫の主配置のcoverageとして導出し、範囲外の関連参照はrelatedProblemIdsに分離する。一般技法を直接扱う問題の自然な配置が親節の場合はそこに残し、葉へ形式的に押し込まない。

Unitは前提DAGを満たすtopological
orderとし、既存の基礎→応用rankを同順位比較に使う。Problemは必要技能の前提閉包の真部分集合を先行させ、同時に置ける場合は解法の基本性、前提の深さ、技能数・複合性、代表順位、安定IDで決める。独立した難易度評価は未収集のためcontest番号・出題枠で代用しない。順序とcoverageを生成元・canonical
projectionの両方で検証する。

Unit本文は概念とアルゴリズムの通常の概説とし、HLDの分解・light辺数・path
queryの計算量などを記述する。各Problem固有のauthoring
unitとfull解説原則を維持し、全文執筆と公開切替は後続taskのままとする。
