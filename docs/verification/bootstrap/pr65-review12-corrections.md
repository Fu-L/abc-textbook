# PR #65 第十二回レビューの本文補修

対象: <https://github.com/Fu-L/abc-textbook/pull/65#pullrequestreview-5401737525>

全868問の解法への接続・計算量を分野別に一覧点検した。DP174問、グラフ・探索172問、データ構造94問、数学147問、文字列・幾何79問、複合202問を対象に、貪欲、正準性、canonical表現、線形空間の固定条件、構成の実現可能性、一対一対応、多重度を横断検索した。短い正当性節とこれらの該当箇所を取り出し、関連する本文・前提Unitへ戻って確認した。指摘3問と追加5問、共通の3単元を補修した。

この横断点検、今回の一般証明、対象を絞った有限検算、全868問の同期検査は異なる。全868問の数学的正しさを独立に証明し直したという記録ではない。

## 根本原因

緩和先の最適値を元の構造へ実現できる理由と、固定条件を加えた後も残る情報の説明が不足していた。「桁構造だから貪欲」「残余基底で最大化」「有理表現で集約」という名前や結論から、読者が必要な交換、不変量、代表解、除外分岐を補う状態になっていた。

数値上の下界と配置による達成を別々に証明し、条件固定後は代表解と自由空間を一組で保持する。元の非空条件は選択係数のkernelで確認する。射影した幾何は全座標で検査する。巨大な同値要素は個数を展開せず、圧縮した処理回数から上界を導く。これらを共通Unitと[執筆手順](../../operations/problem-shards.md#緩和の達成と固定後の情報を点検する)へ反映した。
