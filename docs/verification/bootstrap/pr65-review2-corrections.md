## 根本原因と本文の修正

解法を短く要約する際に、対象を数える単位・初期状態・最後の回答式が落ちていた。また、関数方程式や畳み込みの結論から実装へ至る係数・因果順が未定義であり、同じ主張の本文とClaimの偶奇も食い違っていた。構造検査の成功ではこれらの数学的な問題は発見できない。

architectureとshard執筆手順を具体化し、inventoryの短い分析をfull解説の完成本文として扱わないこと、状態・初期値・遷移係数・回答式を接続すること、本文とClaimを同時に修正することを明記した。独立検算をCIへ追加した。
