## 根本原因と補修基準

係数の結論だけを記すと、距離の和がN−1であることを落とした一つずれを見逃す。アルゴリズム名から計算量へ飛ぶ説明は、前提Unitに実際の手順があるかを確認しない限り読者が再構成できない。「両方向」のような省略は、目的費用の有向arcと残余逆辺、二つの異なる閾値の方向を曖昧にする。

これらを最小入力だけの個別補修で済ませず、元の条件から係数と境界を導き、還元の各操作を列挙し、初期状態から最終出力までつなげる基準で点検した。前提で学べるアルゴリズムを採用するときは該当Unitへ明示的に接続する。本文にない高度な実装を暗黙の前提にしない。ARC・AGC・CF
Div.
1・UCUPへ応用するための、不変量と実行手順を備えた典型として説明する。[執筆手順](../../operations/problem-shards.md#高度な典型の前提と境界の点検)にも同じ基準を追加した。
