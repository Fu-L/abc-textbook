全868問の解法・正当性・計算量を分野別に一覧点検した。DP174問、グラフ・探索172問、データ構造94問、数学147問、文字列・幾何79問、複合202問について、短い証明や交換、等号、符号係数、構成の必要性を横断検索し、該当する本文と前提Unitを確認した。指摘3問に加え、同じ種類の説明不足が見つかった5問と共通3単元を補修した。

## 根本原因

ABC373
Eでは「真に多い票」の条件から必要票数を導いた後、その式の正になる境界を誤っていた。同期検査は同じ誤りを本文・Claim・HTMLへ複製できるため、式とは独立した敵対配分の列挙が必要だった。

残る指摘では、典型名や最終係数を宣言した後、その成立理由を読者が補う状態になっていた。交換後の両者の制約、費用差、縮約後の問題、符号和の相殺と初期値を具体化した。構成問題では十分な構成と必要条件を区別し、厳密不等号では同値・残資源0・予算等号を検算する。この点検方法を共通Unitと[執筆手順](../../operations/problem-shards.md#再検査と編集)へ反映した。
