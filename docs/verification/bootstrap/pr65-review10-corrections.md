# PR #65 第十回レビューの本文補修

対象: <https://github.com/Fu-L/abc-textbook/pull/65#pullrequestreview-5401313426>

全868問を、考察の到達点、正当性、実装上の注意、時間・空間の対応から横断点検した。対象はデータ構造94問、DP174問、グラフ・探索172問、複合202問、数学147問、文字列・幾何79問。各領域の説明と計算量を一覧で照合し、積木・次数打切り・small-to-large・凸DP・費用変換・交換証明などの全出現を検索した。疑わしい問題は全文と前提Unitへ戻り、今回の補修対象は公式問題・個別解説と再照合した。指摘4問に加えて6問、関連する2単元を補修した。この横断点検は全868問を個別に独立証明したものではない。

## 根本原因

局所的な漸化式や典型名から最終式へ進み、途中で維持する情報と全体の保証を省いていた。次数打切りは一つの積を短くするが下層の全積を消さない。凸関数は折点の位置だけでは値や大きな傾きを再現できない。支持数の削減は交換の具体式と全場合の網羅が必要で、非負費用化には実際の辺と経路費用を示す必要がある。

同じ基準を他の問題へ適用し、合成の順序・単位元・終端値、旧状態を読む時点、対象の根、厳密な端点、整数表現と復元まで接続した。ARC・AGC・CF
Div.
1・UCUPで条件の異なる問題に転用するとき、読者が不変量と費用の課金先からアルゴリズムを再構成できる説明を目指す。[執筆手順](../../operations/problem-shards.md#局所操作から全体の保証へ戻す点検)にも共通の点検基準を反映する。

## 独立検算

`pr65-review10-mathematical-checks.py`はPython
3.9以上・追加依存なし。本文の手順を、元の合法操作・全探索・直接DPと比較する。

- ABC267 Ex:
  6要素以下の全三値配列で4,368件の偶奇係数を全subset列挙と比較。M=16で下層の次数総和がNとなる3規模も確認。
- ABC271
  Ex: 全256許可maskと81目標の20,736件を格子BFSと比較。二方向では到達しない三方向の反例を含む。
- ABC275 Ex:
  500配列を元の全区間攻撃の最短路探索と比較し、各部分木の関数も直接漸化式と照合。A=B=10^9の葉は少数の境界を評価し、巨大な値域や重みを展開しない。
- ABC214
  H: 全1,024個の頂点順付き5頂点DAGにK=1,2,3を与え、3,072件を元の経路集合の合併と比較。残余最短路は本文と異なるBellman–Fordで検算する。
- ABC224 H:
  500件を元の全カメラ割当て、任意流量の双対全列挙、固定Fのshift費用と比較。C=0と左右の容量差を含む。
- ABC406 G: 1,000件を座標の直接DPと比較。各段の全座標の値と、逆向きclampで復元した経路の費用を検査。
- ABC269 Ex: 500木でaffine合成した多項式を全antichainの列挙と比較。空集合・末端・合成順も検査。
- ABC264 Ex: 500木の全prefixで、根を含む全誘導subsetの連結性・子数・葉の深さから数えた答えと比較。
- ABC229
  H: 高さ4以下の全120列を両手番のminimaxと比較し、400複数列の和を盤面全体のminimaxと比較。厳密なFractionで開区間と分母上界を検査。
- ABC408 G:
  946開区間を小さい分母の全列挙と比較。端点等号、Farey隣接、10^18規模の狭い区間と整数部分も検査。
