# PR #65 第十八回レビューの補修

対象: [review](https://github.com/Fu-L/abc-textbook/pull/65#pullrequestreview-5405198807) と
[issue comment](https://github.com/Fu-L/abc-textbook/pull/65#issuecomment-5978431541)。ABC212-EからABC466-EまでのE問題254本文を確認し、Blocker
3件、Medium 9件、Low 6件と、92本文の考察・正当性間の長文重複を補修した。

## 根本原因と修正

レビュー指摘には三つの原因があった。第一に、局所探索の訪問順を最短距離とみなす、更新順で必要なデータ構造の不変条件を壊す、自己頂点を真の祖先とみなすなど、実装上の前提を本文に固定できていなかった。第二に、短い説明で済むと思い込み、探索範囲・整数境界・禁止遷移・出力仕様を省いていた。第三に、考察の説明を正当性へそのまま複製し、着眼点と証明の役割が分かれていなかった。

## 有限検算

`pr65-review18-mathematical-checks.py` はPython 3.9以上、追加依存なし、乱択なし。

- ABC249-E: 3文字alphabet、N≤6の全文字列とrun DPを比較。
- ABC254-E: 距離3以内の短い閉路グラフでBFSとdepth-limited
  DFSを比較し、DFSの初回訪問が最短距離でない反例を確認。
- ABC281-E: M=2,K=1のslideでinsert-before-erase後のpartitionと和を確認。
- ABC343-E: pair/triple交差から各被覆体積を戻す式を確認。
- ABC387-E: 表の各範囲端で大小条件、桁和、8/9の倍数条件を確認。
- ABC392-E: 三角形、平行二辺、孤立頂点から余剰辺をC−1回使える資源計数を確認。
- ABC424-E: dyadic group処理を文字どおり最長pieceを割る処理と588入力で比較。
- ABC427-E: Tの逆像が初期ごみの場合だけ禁止される遷移を確認。
- ABC434-E: 余剰辺端点を根にする向き付けが全頂点を覆う例を確認。
- ABC449-E: 初期に現れない値が頻度tieへ入る例を確認。
- ABC454-E: 偶数盤面N≤10の全許容欠損位置110件で移動列を実行し、範囲外移動・再訪・欠損訪問がなく全合法マスを通ることを確認。
- ABC459-E: 法の前後を含む小さいDの二項係数をfalling
  productで比較し、二頂点木で自己祖先を除く条件を確認。

これらは本文の根拠になった有限検査であり、未実施の本人レビューを代替しない。
