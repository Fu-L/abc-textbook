## 根本原因

inventoryは分類に必要な短い分析であり、実装可能な全文解説ではない。しかし生成処理には、考察原稿を省くとinventoryの観察・候補・要点を連結してfull解説を作る経路が残っていた。前回の執筆手順の注意だけではこの経路を止められなかった。

`ProblemAuthoringDetailsSchema`で完成した`reasoning`原稿を必須にし、生成時のinventory本文の自動連結を廃止した。既存本文からの証跡再生成では、その本文の考察を明示的に渡す。回帰テストは考察なし・空原稿を拒否し、実際のshard生成で完成原稿へinventoryを追記せず、例や演習も追加しないことを確認する。構造検査で数学的な完全性を保証する仕組みは作らず、本文点検と独立モデルによる検算を使う。

教科書の点検手順に、同一端点・同深さ、単一辺と経路の集計単位、オンライン積の局所添字、補助過程の出口と真の停止、巨大合同状態の全更新数、部分木サイズによる次数打切りを追加した。既存の学習成果への配置と読む順は維持し、各問題の典型から具体的な計算へ至る説明を補った。
