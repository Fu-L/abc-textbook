## 根本原因と点検の変更

完成原稿を必須にした前回の修正後も、「周期」「Monge
DP」「Lagrange双対」などの典型名を記すだけで、変形の仮定・実行順・元の答えへの換算まで示していない原稿が残っていた。構造検査と本文・Claimの一致は、これらの数学的な省略を検出しない。

今回の補修は、各問題で変換前後の等式、基底と例外、具体的なoracle、回答復元、実際に使うアルゴリズムの計算量を一本につなぐ。執筆手順にも、正規化因子、根と非木辺、有限環の前周期、同じ層のDPの確定順、支持線の整数性と主解の復元を点検項目として追加した。原稿の代わりにセキュリティ機構や一般的な検証フレームワークを増やす変更は行っていない。

CIの失敗は、前回追加した生成回帰テストが全868問の文脈と出典を読み込むのに、既定の5秒のtimeoutを使っていたことが原因だった。この一件に30秒のI/O予算を設定し、考察原稿を省略できない回帰テスト自体は維持した。

各本文は既存の学習成果・前提関係へ接続したまま、完成原稿を編集した。正当性を変更した問題ではfrontmatterのcorrectness
