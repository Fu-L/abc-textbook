## 発動条件と見分け方

### 半環行列・min-plus/max-min遷移

遷移の結合と候補選択を半環の積・和として行列化し、結合則を使って固定長walkを二分累乗または区間積で処理する。

検索語: max-min matrix exponentiation、min-plus matrix exponentiation、半環行列累乗

未知問では、対象・操作・保つべき量・求める量を言葉にし、上の定義をすべて満たすかを確認します。名称の一致だけでは採用しません。

## ガイド例

### 例 1 — 遷移を半環行列として定義し、結合則と単位元を保つ二分累乗・区間積で巨大回数の最適化遷移を計算できる

題材: [ABC236 G「Good Vertices」](https://atcoder.jp/contests/abc236/tasks/abc236_g)

#### このOutcomeを支える根拠

- 巨大な正確歩数の最小 bottleneck 到達時刻を、(min,max) 半環の行列累乗で求められる。

#### 観察

- 辺の追加時刻をその辺の重みとすると、時刻 t までにちょうど L 辺で到達可能とは、使用辺の最大重みが t 以下の L-step walk があることと同値である。
- 求める最早時刻は、頂点 1 から各頂点へのちょうど L 辺 walk が持つ最大辺重みの最小値という bottleneck DP になる。

#### 候補を比較する

- **採用**: 辺時刻行列を、加法を min、乗法を max とする半環上で累乗し、長さ L の walk の最小 bottleneck を一括計算する。 — 二つの walk を連結すると最大辺重みは max、経路候補から最良を選ぶ演算は min で、行列積の結合則により二分累乗できる。
- **棄却**: 移動回数 i＝1 から L まで、各辺で bottleneck DP を一段ずつ更新する。 — L が 10 億まであり、移動回数に比例する反復はできない。

#### 鍵となる着眼

- (P⊗Q)_{ij}=min_k max(P_{ik},Q_{kj}) は、前半と後半の walk を中継点 k で連結したときの bottleneck 最小化そのものである。

#### アルゴリズムへ接続する

時刻付き有向グラフの exact-length bottleneck path DP を (min,max) semiring の行列積へ写し、隣接行列の L 乗を繰り返し二乗法で初期ベクトルへ作用させる。


## 転用するときの確認

- **半環上の行列累乗**: 固定長 walk の DP 遷移が結合的な二演算で行列積と同じ形になり、長さが巨大なとき。 適用: 通常の和・積を min・max に置換し、二分累乗で L 回の遷移を合成する。
- **bottleneck path**: 経路費用が辺重みの和でなく最大値で、候補経路間では最小を取りたいとき。 適用: 辺の追加時刻を重みとし、walk の最大辺時刻をその頂点が良くなる時刻として最小化する。
- 行列累乗で walk を数えるときは、exact length と at most length を区別し、自己ループの有無を入力通りに保つ。
- DP の一段遷移に min と max が現れたら、通常の行列積の和・積を置換した半環として結合できるか確認する。
- 時間増加グラフでは、最早時刻を「経路中の最大追加時刻の最小値」へ変換すると静的な path 問題になる。
