# Matroidの独立性・greedy・線形交差

導入対象の目安: **黄色（2000–2399）**。独立性と交換公理を使い、貪欲法の成立範囲を整理する入口。

対象色の読み方は[本書の読み方](/learn/modeling/)を参照してください。

## 概要

安いものから選び、条件を壊す候補だけを飛ばす貪欲法は、どの選択問題でも正しいわけではない。ベクトルの線形独立性や、辺集合が森であるという条件では、選択の正しさを「独立集合」と「交換公理」で共通に説明できる。この構造を matroid（マトロイド）と呼ぶ。

まず一つの matroid で何を確かめれば貪欲法を使えるかを学び、その後に二つの独立性条件を同時に課す場合へ進む。

## 考え方

### 三ベクトルから独立集合・基底・rankを知る

$$\mathbf F_2$$ は、成分を $$0,1$$ とし、加算を XOR で行う二元体である。選べる要素を、次の三つのベクトルとする。価格は順に $$1,2,3$$ とする。

$$
a=(1,0),\qquad b=(0,1),\qquad c=(1,1)
$$

選べる要素全体の集合を $$E=\{a,b,c\}$$ と書く。ここでは、選んだベクトルが線形独立である集合、つまり空でない部分集合の XOR が $$0$$ にならない集合を**独立集合**とする。全ての部分集合を調べると、次のようになる。

| 選ぶ集合 | 独立性と理由 |
| --- | --- |
| $$\varnothing$$ | 独立。非空の部分集合がない |
| $$\{a\},\{b\},\{c\}$$ | 独立。どれも零ベクトルではない |
| $$\{a,b\},\{a,c\},\{b,c\}$$ | 独立。異なる二本なので、一本でも二本の XOR でも $$0$$ にならない |
| $$\{a,b,c\}$$ | 従属。$$a\oplus b\oplus c=0$$ になる |

独立集合に、残りのどの要素も追加できなくなったら**極大**という。「極大」は追加できないという意味で、個数が最大かどうかは定義に含まない。極大な独立集合を**基底**と呼ぶ。この例の基底は三つの二要素集合で、価格の合計はそれぞれ $$3,4,5$$ である。

集合 $$X\subseteq E$$ に含まれる独立集合の最大サイズを $$\operatorname{rank}(X)$$（rank、階数）と呼ぶ。この例では $$\operatorname{rank}(E)=2$$ であり、どの基底も二本で全ベクトルを XOR で作れる。価格順に $$a,b$$ を採用すると、$$c=a\oplus b$$ は作れる値を増やさないので拒否し、費用 $$3$$ の最小基底を得る。各判定の手順と最適性は[子単元の matroid greedy](/learn/combinatorics-algebra/matroid-greedy/)で追う。

### 貪欲法を支える三つの公理

一般に、有限の要素集合 $$E$$ と、独立とみなす部分集合を全て集めた族 $$\mathcal I$$ を考える。次の三条件を満たす組 $$(E,\mathcal I)$$ が matroid である。

1. 空集合は独立である: $$\varnothing\in\mathcal I$$。
2. 独立集合の部分集合も独立である（遺伝性）。
3. 独立集合 $$A,B\in\mathcal I$$ が $$|A|<|B|$$ を満たすなら、ある $$e\in B\setminus A$$ を $$A$$ に加えても独立である（交換公理）。

三つ目は、まだ選択数が少ない側には、大きい独立集合から一つ追加する余地があるという条件である。例えば $$A=\{c\},B=\{a,b\}$$ なら、$$a,b$$ のどちらを $$A$$ に追加しても独立になる。

交換公理により、極大独立集合は全て同じサイズになる。もし基底 $$A$$ より大きい独立集合 $$B$$ があれば、$$A$$ に一つ追加できて極大性に反するからである。同じ議論は任意の候補集合 $$X\subseteq E$$ の中でも成り立つため、$$X$$ 内で極大まで選べばサイズは必ず $$\operatorname{rank}(X)$$ になる。これが、重み順に見た候補のどの範囲でも、貪欲法が選択数で損をしない理由になる。

### 線形独立性と森では、何を判定するか

**独立性 oracle（判定手続き）**は、与えた集合が独立かを返す処理を指す。貪欲法では、現在の独立集合に候補を一つ加えてよいかを問い合わせる。matroid であることの証明と、判定を速く実装することは別の仕事である。

- **線形 matroid**: ベクトルの線形独立な集合を使う。空集合・遺伝性は線形独立性から従う。交換公理は、$$|A|<|B|$$ のとき、独立な $$B$$ の全ベクトルが $$A$$ の張る空間に入ることはない、と次元を比較すれば分かる。oracle は候補を現在の基底で消去し、零になれば拒否、零でなければ採用して基底を更新する。$$\mathbf F_2$$ 上の実装は [XOR線形基底](/learn/combinatorics-algebra/xor-linear-basis/)へ進む。
- **グラフ的 matroid**: 無向グラフの辺を要素とし、閉路を持たない辺集合（森）を独立とする。辺を減らしても森である。森 $$A,B$$ で $$|A|<|B|$$ のとき、$$B$$ の全辺が $$A$$ の各連結成分内に収まると仮定すると、各成分内で $$B$$ が持てる辺数は頂点数から一を引いた数以下なので、合計も $$|A|$$ 以下となり矛盾する。従って $$A$$ の異なる成分を結ぶ $$B$$ の辺を追加できる。oracle は Union-Find で両端が別成分なら採用・併合し、同じ成分なら拒否する。重みの小さい順に行うと Kruskal 法になる。

### 二つのmatroidを同時に課すと交換できないことがある

四頂点を順に結ぶ三辺の道を考える。辺を $$e_1=\{v_0,v_1\}$$、$$e_2=\{v_1,v_2\}$$、$$e_3=\{v_2,v_3\}$$ とする。端点を共有しない辺の集合を matching（マッチング）という。この道の matching は、空集合、三つの一辺集合、$$\{e_1,e_3\}$$ の計五つである。

$$A=\{e_2\}$$ と $$B=\{e_1,e_3\}$$ はどちらも matching で、$$|A|<|B|$$ である。しかし $$e_1$$ を $$A$$ に足すと $$v_1$$、$$e_3$$ を足すと $$v_2$$ が重なる。$$B\setminus A$$ のどれも追加できず、交換公理が壊れる。$$A$$ は極大だが最大ではなく、中辺を先に採用するだけで最大の二辺を逃す。

この matching の条件は、実は二つの matroid の共通条件である。道を二部グラフとして、片側を $$U=\{v_0,v_2\}$$、もう片側を $$V=\{v_1,v_3\}$$ に分ける。

| 課す条件 | 辺の分割（各グループから高々一本） |
| --- | --- |
| $$U$$ 側の各頂点で高々一本 | $$\{e_1\},\{e_2,e_3\}$$ |
| $$V$$ 側の各頂点で高々一本 | $$\{e_1,e_2\},\{e_3\}$$ |

それぞれは**分割 matroid（partition matroid）**である。空集合と遺伝性を満たし、$$|A|<|B|$$ なら、$$B$$ が一本選んでいて $$A$$ がまだ選んでいないグループがあるので、そこから一辺追加できる。一方、両方を同時に満たすと matching になり、上の反例が生じる。一方で追加できる辺が、もう一方でも追加できるとは限らないのである。

## 成立条件と計算量

単一 matroid の最適基底は、重み順に oracle で独立性を確かめる貪欲法で求まる。候補数を $$m=|E|$$、一回の追加判定・更新の費用を高々 $$T$$ とすると、ソートを含む時間は $$O(m\log m+mT)$$ である。具体的な判定費用と保存領域は oracle の実装で決まる。

二つの matroid の共通独立集合を最適化する**matroid 交差**では、この貪欲法の保証は失われる。一般の matching や交差を同じ選択手順で解けるとは考えない。[線形matroid交差の乱択rank判定](/learn/combinatorics-algebra/linear-matroid-intersection/)では、二つの制約がともに線形表現できる場合に、共通独立集合の最大サイズを乱択行列の rank で調べる。ABC399 G の森林・色別上限もこの側の問題であり、集合の復元まで rank 一回でできるとは限らない。

概念上の親: [組合せ・多項式・線形代数](/learn/combinatorics-algebra/)。問題へ進む前に、下記の直接前提のうち未習得の単元を確認する。
