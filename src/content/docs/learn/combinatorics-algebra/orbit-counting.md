# 群作用・軌道数え上げ

## 概要

### 群作用・軌道数え上げ

群作用の固定点を作用素のcycle typeごとに数え、BurnsideまたはPólyaで軌道数を得る。

## 前提と範囲

共通前提: prereq-abc-advanced-v1 (1.0.0)。

追加前提: 同値な状態を正規化する。

状態・配置の正規化で得た考え方と実装を再利用し、群作用・軌道数え上げの発動条件・正当化・境界を重複なく学ぶ。

### このUnitでは扱わないもの

- 群作用・軌道数え上げの発動条件・不変量を使わず、実装部品だけを偶然共有する解法。
