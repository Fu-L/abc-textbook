# 拡大有限体の表現と四則演算を構成する

## 概要

### 拡大有限体の表現と演算

素体上の多項式剰余または基底座標で有限体の元を表し、標準化された加減乗除を構成する。

## 前提と範囲

共通前提: prereq-abc-advanced-v1 (1.0.0)。

追加前提: 法上の四則演算・高速累乗・逆元。

素体上の演算を土台に、既約関係で元を標準化し、加減乗除が閉じる拡大体として扱う。

- 素数法上の通常の四則演算だけで閉じる計算、および環上で逆元の存在を仮定できない演算。
