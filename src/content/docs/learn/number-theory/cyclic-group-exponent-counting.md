# 巡回群を指数化して数える

## 概要

### 巡回群の指数化・位数別数え上げ

巡回部分群の元を指数へ写し、gcd・位数・約数格子で分類して重複なく数える。

## 前提と範囲

共通前提: prereq-abc-advanced-v1 (1.0.0)。

追加前提: 乗法的位数から最小周期を求める。

乗法的位数とその約数分類を先に学び、巡回群の元を指数へ写して位数別に重複なく数える。個別問題で必要な約数Möbius反転はsupporting readinessとして接続する。

- 乗法的位数から最小周期だけを求める問題。
