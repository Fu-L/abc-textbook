# 数論

導入対象の目安: **緑色（800–1199）**。素因数・gcd・剰余を整数条件の表現として使い分ける入口。

対象色の読み方は[本書の読み方](/learn/modeling/)を参照してください。

## 概要

素因数・gcd・Bézoutから、法上の演算と逆元、CRTへ進む。整数境界の正確な扱いを揃えた後、剰余周期・乗法的位数・巡回群の指数化をつなぎ、BSGSで反復到達時刻を探索する。床和と有理近似ではEuclid互除法による縮小を比較し、Stern–Brocot木の経路へ応用する。発展は数値半群、素体でも使えるFrobenius恒等式、拡大有限体、Gaussian整数、総和篩の順に読む。群の計数には約数反転、総和篩には商一定区間という既習の道具を持ち込む。

### 数論構造への変換

整数条件を合同・整除・指数・約数格子などの数論構造へ変換する。

### 習得する技能

- 整数条件を合同・整除・指数・約数格子などの数論構造へ変換する。その発動条件、正当性、計算量を説明し、未知問へ実装できる。

## 考え方

整数を値のまま扱うか、素因数指数・剰余・gcd・周期へ移すかを選ぶ。巨大な範囲は商の一定区間やEuclidの互除法で圧縮し、除算には可逆性や丸めの条件を付ける。

## 成立条件と計算量

入力値Uに対するlog U、√U、Uの費用は大きく違う。modを取っても割算が自由になるわけではない。各単元で整数の存在条件と、答えを計算する手順を分けて確認する。
