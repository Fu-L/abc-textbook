# 乗法的位数から最小周期を求める

## 概要

### 乗法的位数・最小周期

合同反復の最小正周期をmultiplicative orderへ帰着し、群位数の約数を割り落として求める。

## 前提と範囲

共通前提: prereq-abc-advanced-v1 (1.0.0)。

追加前提: 法上の四則演算・高速累乗・逆元、素因数分解と約数構造。

合同算術と約数分解を使えることを前提に、最小周期を乗法的位数へ帰着して約数から絞る。

- 約数格子上の指数計数・包除。
