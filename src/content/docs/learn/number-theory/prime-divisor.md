# 素因数分解と約数構造

## 概要

### 素因数・約数分解

整数の条件を素数ごとの指数や約数格子の条件に分解する。

## 前提と範囲

共通前提: prereq-abc-advanced-v1 (1.0.0)。

追加前提: なし。

初歩的な素因数分解を、指数vectorと約数格子へ条件を分解する道具として発展させる。

- 床関数や整数根の値が一定となる区間への分割。
