## ガイド例

### 例 1 — Z[i]での素因数分解と共役を用い、整数の二平方和表現をprime exponentごとに構成・数え上げる。その発動条件、正当性、計算量を説明し、未知問へ実装できる

題材: [ABC444 G「Kyoen」](https://atcoder.jp/contests/abc444/tasks/abc444_g)

選定理由: 4 mod 3 の素数指数が奇数なら表現は0で、4 mod 1 の素数 p=ππ̄ では π と π̄ への指数配分 e+1 通りが自由度になる。

この例で扱う範囲: ここでは次の局所的な観察から対象技能を導く。X^2+Y^2=N の解を N の素因数表示から数えたいとき。 問題全体への接続は併用技能を学んだ後に読む。

#### このOutcomeを支える根拠

- 素因数表示された巨大半径の円について、指定合同類に属する整数格子点数を有限剰余分布から数えられる。

#### 観察

- 円周上の整数点条件は X^2+Y^2=N と X≡-A、Y≡-B (mod C) に整理できる。X+iY をガウス整数と見ると norm N の因子分配問題になる。

#### 候補を比較する

- **採用**: N の有理素因数をガウス素因数へ分解し、共役 pair の指数分配が作る剰余 (X mod C,Y mod C) の頻度分布を素数ごとに求めて畳み込み、指定剰余の個数を得る。 — ガウス整数の一意分解により norm N を持つ全候補が指数分配で漏れなく表され、mod C 上の乗算状態は C^2 個なので巨大指数列も周期で圧縮できる。
- **棄却**: |X|,|Y|≤sqrt(N) を走査して X^2+Y^2=N と合同条件を直接検査する。 — N の指数は巨大で sqrt(N) を数値化・列挙できず、素因数表示を利用していない。

#### 鍵となる着眼

- 4 mod 3 の素数指数が奇数なら表現は0で、4 mod 1 の素数 p=ππ̄ では π と π̄ への指数配分 e+1 通りが自由度になる。
- ガウス整数を mod C で掛け続ける列は C^2 状態の functional graph 上を進むため、先頭・周期・末尾の頻度をまとめられる。

#### アルゴリズムへ接続する

2、1 mod4、3 mod4 の素因数を分類し、必要な p=x^2+y^2 を構成する。各因子で可能なガウス剰余の頻度を周期検出して作り、現在分布と C^2×C^2 の積剰余 convolution で merge し、単元 i^k も掛けて目標剰余を読む。


## 転用するときの確認

- **ガウス整数による二平方表現**: X^2+Y^2=N の解を N の素因数表示から数えたいとき。 適用: norm の因子を共役ガウス素数へ分配する。
- **有限状態の周期集計**: 巨大指数にわたる乗法列を小さな modulus 上で数えたいとき。 適用: C^2 個の剰余状態の functional graph として頻度を求める。
- 指数が巨大でも、有限環上の累乗列は有限状態なので周期前後を数式で集計できる。
- まず合同条件なしの 4∏(e_p+1) を導き、各指数選択がどのガウス剰余へ写るかを小さな C で列挙してから周期圧縮へ進む。
