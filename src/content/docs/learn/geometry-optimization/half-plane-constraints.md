# 半平面制約・凸領域の共通部分

習得対象の目安: **黄色（2000–2399）**。凸多角形を辺ごとの半平面に変換し、平行移動した全領域への包含を最強の制約で判定する。

対象色の読み方は[本書の読み方](/learn/modeling/)を参照してください。

## 概要

### 半平面制約・凸領域の共通部分

向き付き直線の左側を線形不等式とし、平行制約を最強の境界へ集約して凸領域の包含・共通部分を扱う。

### 習得する技能

- 凸多角形を向き付き辺の線形半平面制約へ変換し、平行移動後も左辺が同じ制約を最強の右辺へ集約して共通部分への包含を判定できる。

## 考え方

反時計回りの凸多角形の頂点をv_i、辺方向をe_i=v_(i+1)−v_iとする（添字は巡回）。点zが多角形の内部または境界にある必要十分条件は、全辺について `cross(e_i,z−v_i)≥0`。凸性により辺の左半平面の共通部分がちょうど元の多角形になる。時計回りなら先に頂点列を逆にし、境界を含むかは不等号で固定する。

平行移動t_j後は `cross(e_i,z)≥cross(e_i,v_i+t_j)` となる。固定iでは左辺が全移動で同じなので、全多角形への包含は `cross(e_i,z)≥H_i`、`H_i=max_j cross(e_i,v_i+t_j)` と同値。各辺のH_iを前計算し、各query点についてN本を判定すればよい。全条件を満たす点がなければ共通部分は空だが、包含queryのために交点や共通部分の頂点を構築する必要はない。

集約できるのは同じ向き・同じ尺度の左辺を持つ制約である。逆向きの辺は上限と下限に対応する別条件になる。異なる多角形の一般の半平面共通部分を実際に構築する算法は、角度sortとdeque、平行線・非有界領域の処理を別途要し、この包含判定とは区別する。

## 成立条件と計算量

N辺、M個の平行移動、Q個の点queryならO(NM+NQ)時間、HのO(N)補助空間。外積は整数座標なら整数で比較できるが、積と差に必要な整数幅を確保する。非凸多角形では全辺の左半平面の共通部分が元の内部とは一致しない。
