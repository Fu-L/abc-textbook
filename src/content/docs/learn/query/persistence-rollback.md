# 構造を共有して過去の版を保存・復元する

## 概要

更新で変わる箇所を局所化し、未変更部分の共有または履歴の巻き戻しで過去の版を扱う。

## 前提と範囲

共通前提: prereq-abc-advanced-v1 (1.0.0)。

追加前提: なし。

### このUnitでは扱わないもの

- 区間更新作用の遅延評価。
