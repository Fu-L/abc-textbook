# モデル変換とアルゴリズム設計

このページは **章** です。分野全体の索引として、技能の境界と学ぶ順序を俯瞰します。各技能の定義を混同せず、必要な節・小節へ降りるための地図として使ってください。

読み終えたら、手法名を覚えたかではなく、未知問から発動条件を抽出し、候補を比較し、正当化と計算量を説明できるかで自己評価します。

## この単元でできるようになること

- 問題固有の語を再利用可能な対象・操作・不変量に置き換えられる。

## 前提・学習順・対象外

- 共通前提: `prereq-abc-advanced-v1` version `1.0.0`
- 追加前提: なし
- この位置で学ぶ理由: 問題文の操作を再利用可能な対象・不変量へ言い換え、探索・貪欲・分割手法を選ぶ共通の視点を最初に作る。

### この単元では扱わない範囲

- なし

## 下位単元と学習順

以下は canonical standard order に沿った章内カリキュラムです。定義・証明・実装境界・Outcome到達確認は各リンク先で扱い、この章では経路選択に必要な境界を示します。

1. [単調境界を証明して探索する](./monotone-search.md)（標準順 12）— 判定結果が一方向に変わることを証明し、巨大な値域から成功・失敗の境界を二分探索で求める。
2. [尺取り法・sliding windowで連続区間を走査する](./two-pointers-window.md)（標準順 14）— 窓の不変条件と左右端の単調性を使い、各要素を高々定数回だけ処理して連続区間を列挙する。
3. [疎なkeyの順序を保ってdense indexへ圧縮する](./coordinate-compression.md)（標準順 15）— 比較に必要なのが順序と等値性だけであることを確認し、疎な初期値・将来更新値・event座標をsort-uniqueしたdense indexへ写す。
4. [event順にactive集合を更新する](./event-sweep.md)（標準順 19）— 値・時刻・座標順にeventを並べ、同値eventの処理順を決めてactive集合を増分更新する。逆向き処理や寄与分解とは不変量が異なるため独立に学ぶ。
5. [同値な状態を正規化する](./normalization.md)（標準順 22）— 対称な状態を同一視できると探索やDPの状態数を減らせるため、同値類の標準形と不変量を先に定める。
6. [時間を逆向きにして未来依存を消す](./reverse-offline.md)（標準順 23）— 削除・上書き・未来依存を含む更新列を逆向きに読み、追加だけ・first-writeだけなどの単調な処理へ変換して元の時刻へ答えを戻す。
7. [局所寄与へ分解して集計順を交換する](./contribution-reordering.md)（標準順 24）— 答えを要素・組・成分ごとの局所寄与へ一意に分け、各対象が何回数えられるかを証明して二重和・積・期待値の集計順を交換する。
8. [交換論から選択順を導く](./greedy-exchange.md)（標準順 25）— 局所選択を交換論で正当化し、候補を安全に確定できる順序を導く。
9. [候補数を界して全列挙・有限case分解する](./bounded-enumeration.md)（標準順 26）— 制約、生成パラメータ、固定選択数、有限な幾何caseから候補総数を先に界し、全候補を漏れなく評価する。
10. [対話protocolを守って情報を取得する](./interactive-protocol.md)（標準順 28）— 問い合わせ形式・回数上限・応答依存性・flushを明示し、通常のアルゴリズムをjudgeとの対話列として安全に実行する。
11. [探索空間を分けて照合・再帰分割する](./divide-enumeration.md)（標準順 52）— 探索空間を独立な二集合または再帰部分へ分けるか、部分結果をbalancedな積木・remainder tree・CDQで合成し、重複なく扱える入力規模を広げる。
12. [軽重分類と償却解析で総仕事量を抑える](./decomposition-amortization.md)（標準順 55）— 各操作ではなく操作列全体の変化回数を数え、軽重分類や一度限りの移動で総計算量を抑える。
13. [基準witnessから変更影響を局所化する](./change-impact-localization.md)（標準順 57）— 変更前の最適解や実行列をwitnessとして固定し、それが壊れない変更では答えも変わらないことを証明して再計算対象を絞る。
14. [成立証明から構成解を復元する](./constructive-witness.md)（標準順 75）— 存在条件の証明に対応する親・選択・局所操作を記録し、実際の構成へ戻す。
15. [乱択の成功条件と誤り確率を設計する](./randomized-algorithms.md)（標準順 78）— 乱数が作る事象と成功条件を分離し、独立試行による誤り確率の減衰や決定的な事後検証まで設計する。
16. [bitwise greedyによるmask最適化](./bitwise-greedy-feasibility.md)（標準順 87）— 上位bitから候補maskを仮定し、残り問題のfeasibility oracleでそのbitを保持/除去できるか決める。その発動条件と正当化原理を比較可能な独立教材として学ぶ。
17. [backtracking・可逆な探索状態](./backtracking-search.md)（標準順 88）— 再帰へ入る直前に局所選択を反映し、復帰時に必ずundoして現在pathだけの制約を保ちながら探索木を列挙する。その発動条件と正当化原理を比較可能な独立教材として学ぶ。
18. [parallel binary search・多数境界の判定共有](./parallel-binary-search.md)（標準順 93）— 単一queryの単調境界を二分探索できるようになった後、多数queryのmidをroundごとに束ね、一方向更新できる判定器を共有する。
19. [情報量下界・query符号設計](./information-theoretic-query-design.md)（標準順 95）— 応答alphabetとquery回数から識別可能状態数の下界を出し、その下界に一致するcodeword割当と復号を構成する。その発動条件と正当化原理を比較可能な独立教材として学ぶ。

## 発動条件と見分け方

### モデル変換

問題固有の操作を再利用可能な構造・順序・境界の問題へ変換する。

検索語: modeling、problem reduction、問題の言い換え

未知問では、対象・操作・保つべき量・求める量を言葉にし、上の定義をすべて満たすかを確認します。名称の一致だけでは採用しません。

## ガイド例

### 例 1 — 問題固有の語を再利用可能な対象・操作・不変量に置き換えられる

題材: [ABC213 H「Stroll」](https://atcoder.jp/contests/abc213/tasks/abc213_h)

#### このOutcomeを支える根拠

- 過去の DP 値と固定核の畳み込みで定まる時系列を、分割統治と NTT で因果順に高速評価できる。
- DP の遷移和を係数列の畳み込みとして読み替えられること。
- NTT の畳み込みと、左を解いてから右へ寄与を送る CDQ 分割統治の順序を理解していること。
- 正の道路長が時間方向の厳密な前進を保証するため、左区間から右区間への寄与だけを送る分割統治が成立する。 再利用の観点: 再帰的な畳み込み式では、添字が必ず増える因果性を見つけると、確定済み区間から未確定区間へのオフライン更新に分解できる。
- 時間 DAG 上の自己参照型畳み込み DP を CDQ 型の分割統治で因果順に確定し、各区間間の道路遷移を NTT による多項式積として高速化する。
- 時間区間を分割統治し、左半分で確定した DP 列と各道路の p_i を高速畳み込みして右半分へ寄与させる。 — 未来の値を使わない依存順を守りながら、同じ区間間の畳み込みを NTT でまとめて計算できる。
- 普通の一括畳み込みでは d 自身が未確定なので計算できないが、分割統治なら左区間の確定値だけを右区間へ送れる。
- 無向道路では一つの p_i が両方向の遷移に使われるため、左区間の各端点の系列から反対側へ対称に寄与を加える。
- 時刻 t に街 s へ着く散歩コース数を d[s,t] とすると、道路 i を最後に渡る遷移は、出発側の時系列と長さ別通行方法数 p_i の畳み込みになる。
- 道路の長さは正なので、時刻 t の値は t より前の時刻だけに依存し、時間軸上には循環しない依存関係がある。
- オンライン畳み込みの分割統治: 時系列 DP の現在値が過去列との畳み込みで定まり、全入力列を一度に確定できないとき。 適用: 左時間区間を先に解き、その確定値から右時間区間への畳み込み寄与を加えてから右を再帰的に解く。
- NTT による多項式積: 法が変換に適し、長い係数列どうしの畳み込みを多数まとめて計算するとき。 適用: 街ごとの DP 係数列と道路の長さ別係数列の区間積を求め、対応する到着時刻へ加算する。

#### 観察

- 時刻 t に街 s へ着く散歩コース数を d[s,t] とすると、道路 i を最後に渡る遷移は、出発側の時系列と長さ別通行方法数 p_i の畳み込みになる。
- 道路の長さは正なので、時刻 t の値は t より前の時刻だけに依存し、時間軸上には循環しない依存関係がある。

#### 候補を比較する

- **採用**: 時間区間を分割統治し、左半分で確定した DP 列と各道路の p_i を高速畳み込みして右半分へ寄与させる。 — 未来の値を使わない依存順を守りながら、同じ区間間の畳み込みを NTT でまとめて計算できる。
- **棄却**: 各時刻と道路について、利用可能な全ての道路長を走査して以前の DP 値を加える。 — 時刻の組を二重に扱う畳み込みが道路ごとに発生し、T の二乗規模の計算になる。

#### 鍵となる着眼

- 普通の一括畳み込みでは d 自身が未確定なので計算できないが、分割統治なら左区間の確定値だけを右区間へ送れる。
- 無向道路では一つの p_i が両方向の遷移に使われるため、左区間の各端点の系列から反対側へ対称に寄与を加える。

#### アルゴリズムへ接続する

時間 DAG 上の自己参照型畳み込み DP を CDQ 型の分割統治で因果順に確定し、各区間間の道路遷移を NTT による多項式積として高速化する。

## 下位単元を使い分ける比較例

未知問を見たときは、手法名を思い出す前に「対象」「操作」「保つ量」「求める量」を書き出します。それぞれの下位単元が要求する発動条件と照合し、採用する経路だけでなく、近い候補を棄却する理由も残してください。

- **単調境界を証明して探索する** — 直接到達点: 判定の単調性を証明し、二分探索の成功側・失敗側を設定できる。近いが対象外: 連続窓の両端を一方向に進める尺取り法、および真偽判定の単調境界を持たない三分探索・局所探索。
- **尺取り法・sliding windowで連続区間を走査する** — 直接到達点: 一列の窓または二列の現在blockに関する不変条件を保ち、各pointerを単調に進められる。近いが対象外: 値域上の真偽境界を探す二分探索・パラメトリックサーチ。
- **疎なkeyの順序を保ってdense indexへ圧縮する** — 直接到達点: 初期値・将来更新値・疎なevent座標をsort-uniqueし、順序と等値性を保つdense indexまたは有限状態へ写せる。近いが対象外: 値・時刻順にactive集合を増減するevent sweep、および固定配列・行列を入力順のまま読むだけのscan。
- **event順にactive集合を更新する** — 直接到達点: 値・時刻・座標順にeventを並べ、同値eventの処理順とactive集合の増分更新を設計できる。近いが対象外: 更新を単に逆順へ読む処理、答えの局所寄与だけを集計する順序交換、sort-uniqueしたkeyの添字化、および固定方向の単純scan。
- **同値な状態を正規化する** — 直接到達点: 対称操作で同値な状態の標準形と不変量を選べる。近いが対象外: 交換論による貪欲順の証明。
- **時間を逆向きにして未来依存を消す** — 直接到達点: 時間依存を逆走査・逆操作・last-write時刻で単調または静的にし、元の時点へ答えを戻せる。近いが対象外: 値順eventを前から処理するsweep、時刻を反転せずに行う通常のonline更新、および答えの局所寄与だけを集計する順序交換。
- **局所寄与へ分解して集計順を交換する** — 直接到達点: 答えを独立な局所寄与の和または積に分解し、重複を避けて集計順を交換できる。近いが対象外: active集合を時刻・座標順に更新するevent sweep、更新列を逆から読むだけの処理、および独立な局所寄与へ分解できない集計。
- **交換論から選択順を導く** — 直接到達点: 局所選択の交換または候補の支配関係を示し、安全な順序・候補・caseを確定できる。近いが対象外: 対称操作による状態の正規化。
- **候補数を界して全列挙・有限case分解する** — 直接到達点: 制約・生成パラメータ・固定選択数・有限caseから候補総数を界し、漏れなく全候補を生成・評価できる。近いが対象外: 探索空間を二つへ分けて照合するmeet-in-the-middle、および再帰部分問題へ分ける分割統治。
- **対話protocolを守って情報を取得する** — 直接到達点: 問い合わせ・応答・終了宣言のprotocolを守り、応答依存の探索をquery上限内で実行できる。近いが対象外: 入力を最初からすべて読める通常問題、および問い合わせ上限やflushを持たない模擬入出力。
- **探索空間を分けて照合・再帰分割する** — 直接到達点: 2個の下位Outcomeへ進むための構造索引。近いが対象外: 候補数を制約・生成パラメータ・有限caseで直接界して全列挙する探索、軽重分類による償却解析、および入力木・trie・区間DPの構造をそのまま辿るだけの再帰。
- **軽重分類と償却解析で総仕事量を抑える** — 直接到達点: 3個の下位Outcomeへ進むための構造索引。近いが対象外: 探索空間を分けて候補を列挙・照合するmeet-in-the-middleや分割統治。
- **基準witnessから変更影響を局所化する** — 直接到達点: 基準となる解や経路を証拠に、答えが変わり得る変更だけを特定して再計算を局所化できる。近いが対象外: 存在する解を一つ復元するだけで、変更後も同じwitnessが有効かを判定しない問題。
- **成立証明から構成解を復元する** — 直接到達点: 成立証明に対応する親・局所操作・選択を記録し、要件を満たす構成を出力できる。近いが対象外: 存在判定・個数計算だけで、具体的な解や操作列を復元しない問題。
- **乱択の成功条件と誤り確率を設計する** — 直接到達点: 乱数で選ぶ対象と成功条件を定め、誤り確率を上から評価して必要な反復回数または決定的な事後検証を設計できる。近いが対象外: 誤り確率の評価を伴わない固定hash、および入力全体を確定的に列挙できる探索。
- **bitwise greedyによるmask最適化** — 直接到達点: 上位bitから候補maskを仮定し、残り問題のfeasibility oracleでそのbitを保持/除去できるか決める。その発動条件、正当性、計算量を説明し、未知問へ実装できる。近いが対象外: bitwise greedyによるmask最適化の発動条件・不変量を使わず、実装部品だけを偶然共有する解法。
- **backtracking・可逆な探索状態** — 直接到達点: 再帰の前後で使用状態を対称に更新・復元し、現在pathだけの制約を保って探索木を漏れなく列挙できる。近いが対象外: backtracking・可逆な探索状態の発動条件・不変量を使わず、実装部品だけを偶然共有する解法。
- **parallel binary search・多数境界の判定共有** — 直接到達点: 各queryの未確定区間を保ち、同じroundのmidをbucketして一方向更新できる判定器を共有し、全queryの最小・最大成立境界を求められる。近いが対象外: parallel binary search・多数境界の判定共有の発動条件・不変量を使わず、実装部品だけを偶然共有する解法。
- **情報量下界・query符号設計** — 直接到達点: 応答列の総数からquery数の下界を証明し、それに一致するcodeword割当と復号を構成できる。近いが対象外: 情報量下界・query符号設計の発動条件・不変量を使わず、実装部品だけを偶然共有する解法。

**比較の到達点**: 未知問の構造から下位単元の候補を絞り、採用・棄却を発動条件と対象外の両方で説明できる。


## 転用するときの確認

- **オンライン畳み込みの分割統治**: 時系列 DP の現在値が過去列との畳み込みで定まり、全入力列を一度に確定できないとき。 適用: 左時間区間を先に解き、その確定値から右時間区間への畳み込み寄与を加えてから右を再帰的に解く。
- **NTT による多項式積**: 法が変換に適し、長い係数列どうしの畳み込みを多数まとめて計算するとき。 適用: 街ごとの DP 係数列と道路の長さ別係数列の区間積を求め、対応する到着時刻へ加算する。
- 再帰的な畳み込み式では、添字が必ず増える因果性を見つけると、確定済み区間から未確定区間へのオフライン更新に分解できる。
- 遷移が「過去時刻×長さ別係数」の和なら、まず畳み込み式を書き、未知列を含むため一括変換できない点まで確認する。
- 分割統治の正当性は、再帰へ入る時点でどの時刻からの寄与が既に反映済みかを区間ごとに説明して確認する。
