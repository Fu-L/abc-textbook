# 探索空間を分けて照合・再帰分割する

導入対象の目安: **水色（1200–1599）**。探索空間を独立に分ける場合と、再帰的な小問題へ分ける場合を区別する入口。

対象色の読み方は[本書の読み方](/learn/modeling/)を参照してください。

概念上の親: [モデル変換とアルゴリズム設計](/learn/modeling/)。問題へ進む前に、下記の直接前提のうち未習得の単元を確認する。

## 概要

全体をそのまま扱うと大きすぎるとき、二つに分けて小さい結果から答えを作れないか考える。ただし、分けるだけでは仕事は減らない。どちらの部分に何を計算させ、どの情報でつなぐかが核心になる。

この案内では、二群の候補を独立に列挙して照合する半分全列挙と、同じ形の小問題を繰り返し解いて合成する分割統治を区別する。

## 考え方

### 二群の結果を照合する

40個の物を選ぶ・選ばないで指定の合計を作りたいとする。全体の部分集合は $$2^{40}$$ 通りあり、そのままでは多い。20個ずつに分ければ、各側の部分集合は $$2^{20}$$ 通りになる。

各側について「どれを選んだか」から合計値を計算する。目標が $$T$$ なら、左の合計 $$x$$ に対し、右に $$T-x$$ があるかを探せばよい。右側を並べ替えて二分探索するなどすれば、左右のすべての組を直接試す必要がなくなる。

例えば左が `2, 5`、右が `3, 4` で目標7なら、左の合計は `0, 2, 5, 7`、右は `0, 3, 4, 7`。左0に対する右7と、左7に対する右0が見つかり、選び方は2通りある。元の選択は、左右への制限によって一つの組へ分解される。逆に左右を一つずつ選べば、一つの全体の選択ができる。

この[半分全列挙](/learn/modeling/meet-in-the-middle/)では、「左右を選ぶ自由度」と「結合したときの条件」を分離する。左右を約100万通りずつ作った後、その直積の約1兆通りを全走査したら元に戻ってしまう。照合を検索や集計へ変えられることが必要である。

### 同じ問いを小さい範囲へ渡す

一方、列を昇順に並べ替える問題を考えよう。左半分と右半分をそれぞれ整列できたなら、各側の先頭を比較し、小さい方から取り出して全体を整列できる。半分の整列にも、まったく同じ「半分に分けて整列して併合する」という手順を使える。長さ1まで分ければ、それ以上の操作は要らない。

例えば `4, 1, 3, 2` は、`4, 1` と `3, 2` に分かれ、それぞれ `1, 4` と `2, 3` になる。併合では `1 → 2 → 3 → 4` の順に取り出す。片方が空になったら、残りをそのまま続ける。

この[分割統治](/learn/modeling/recursive-divide-and-conquer/)では、小問題へ渡すのは候補一覧ではなく「その範囲の問い」であり、戻り値から親の答えを構成する。同じ型で小さくなること、戻り値が合成に十分なことを確認する。

### 分割線をまたぐ対象を見失わない

列の逆転数、すなわち $$i<j$$ かつ $$A_i>A_j$$ である組数を数えるなら、左右内部だけでは答えが出ない。左に $$i$$、右に $$j$$ がある組も存在する。

各組は「左内部」「右内部」「左右をまたぐ」のどれか一つに属する。内部は再帰へ渡し、またぐ組だけを親で数えると、漏れも重複もなく扱える。親での集計を速くするため、子からは個数だけでなく整列済みの値列も返す、といった設計が必要になる。

半分全列挙でも境界は重要である。[ABC271 F](/problems/abc271-f/)ではグリッド経路を中間の対角線で分ける。左右の部分経路をつなぐには合流するマスが同じでなければならず、合流マスを両側のXORへ含めた場合は、その重複分も調整する。何を返せば結合できるかを、境界を含めて決めよう。

## 成立条件と計算量

二択を $$N$$ 回行う半分全列挙で、左右の候補数を $$P=2^{\lfloor N/2\rfloor}$$、$$Q=2^{\lceil N/2\rceil}$$ とする。候補を差分更新で生成して、右を整列し各左から二分探索するなら、$$O(P+Q+Q\log Q+P\log Q)$$ 時間、保存に $$O(P+Q)$$ 空間を使う。候補ごとに選択した要素を走査して合計する実装では、その費用も増える。

均等に二分する分割統治では、長さ $$n$$ の処理を $$T(n)$$ とすると、線形時間で合成できる場合は $$T(n)=2T(n/2)+O(n)$$。同じ深さの問題サイズの和が $$n$$、深さが $$O(\log n)$$ なので、合計は $$O(n\log n)$$ になる。各回に一要素しか減らないなら深さは対数にはならない。再帰という形だけで計算量を決めない。

## 前提と範囲

共通前提: prereq-abc-advanced-v1 (1.0.0)。

直接の前提単元: なし。

このUnitを直接前提とする単元: なし。

全列挙、並べ替え、二分探索、基本的な再帰を前提とする。まず二つの下位単元で、照合と再帰的合成の仕組みをそれぞれ学ぶ。分割した問題が独立でない場合や、結合情報が大きすぎる場合には、分割方法を変えるか別の解法を探す。

再帰の形を持つだけで、この手法になるわけではない。入力の木をそのまま辿る探索に対し、ここでは「どこで分け、何を返し、どう合成すれば仕事が減るか」という設計を扱う。CDQや多項式の積木などの発展も、この三つの問いを具体化したものとして読むとよい。

### このUnitでは扱わないもの

- 候補数を制約・生成パラメータ・有限caseで直接界して全列挙する探索、軽重分類による償却解析、および入力木・trie・区間DPの構造をそのまま辿るだけの再帰。
