# ABC215 G - Colorful Candies 2 解説

AtCoder Beginner Contest 215 · G問題 · 600点

この問題の核心は、**期待値の線形性によって色ごとに独立して数え、その後、出現回数の種類が \(O(\sqrt N)\) 個しかないことを利用する**点です。

特に後半の「出現回数の種類が少ない」という性質は、他の問題にも応用できる重要な典型です。

- **計算量：** \(O(N\sqrt N)\)
- **主要な知識：** 期待値の線形性、余事象、同じ寄与の集約、異なる正整数の総和による個数評価

## 1\. 問題を整理する

\(N\) 個のキャンディがあり、それぞれに色が付いています。

\(K=1,2,\ldots,N\) について、\(N\) 個から一様ランダムに \(K\) 個を選んだときの、**選ばれたキャンディに含まれる色の種類数の期待値**を求めます。

制約は \(N\le 5\times 10^4\) です。

キャンディの並び順は答えに影響しません。重要なのは、各色が何個ずつ存在するかだけです。

そこで、全体に存在する色の種類数を \(C\)、各色の個数を

\[
n_1,n_2,\ldots,n_C
\]

とします。もちろん \(\sum_{i=1}^{C}n_i=N\) です。

## 2\. 色の種類数を直接数えるのではなく、色ごとに考える

まず \(K\) を固定して考えます。

選ばれた \(K\) 個に含まれる色の種類数を直接求めようとすると、選ばれる色の組み合わせが複雑になります。

しかし、「色 \(i\) が含まれるかどうか」であれば、ずっと簡単に考えられます。

### 期待値の線形性を使う

色 \(i\) が選ばれたキャンディに含まれていれば \(X_i=1\)、含まれていなければ \(X_i=0\) と定義します。

すると、色の種類数は

\[
X=X_1+X_2+\cdots+X_C
\]

です。期待値の線形性により、

\[
E[X]=\sum_{i=1}^{C}E[X_i]
=\sum_{i=1}^{C}P(X_i=1)
\]

となります。

**各色が選ばれる確率を計算して足せばよい**わけです。

ここでは各色が選ばれる事象の独立性は必要ありません。

### 余事象を利用する

色 \(i\) のキャンディが \(n_i\) 個存在するとします。

この色が1個以上選ばれる確率を直接数えるよりも、1個も選ばれない確率を考えたほうが簡単です。

色 \(i\) 以外のキャンディは \(N-n_i\) 個あるため、

\[
P(X_i=0)=\frac{\binom{N-n_i}{K}}{\binom NK}
\]

です。ただし、\(K>N-n_i\) なら分子を \(0\) とします。

したがって、

\[
P(X_i=1)=1-\frac{\binom{N-n_i}{K}}{\binom NK}
\]

となり、

\[
\boxed{
E_K=C-\frac{\displaystyle\sum_{i=1}^{C}\binom{N-n_i}{K}}{\binom NK}
}
\]

が得られます。

この式が解法の出発点です。

## 3\. 同じ個数の色をまとめる

この式をすべての \(K\) に対して計算すると、1つの \(K\) につき最大 \(N\) 色を調べるため、全体で \(O(N^2)\) 時間かかります。

ここで、式の各項をもう一度見ます。

\[
\binom{N-n_i}{K}
\]

この値は、色の番号や並び順ではなく、**その色のキャンディが何個あるか**だけで決まります。

つまり、同じ個数だけ存在する色は、必ず同じ寄与を持ちます。

### 具体例で考える

次の10個のキャンディを考えましょう。

\[
(1,2,2,3,3,4,4,4,4,5)
\]

各色の個数は次のとおりです。

| 色 | 個数 |
|--------|--------|
| 1 | 1 |
| 2 | 2 |
| 3 | 2 |
| 4 | 4 |
| 5 | 1 |

たとえば \(K=2\) の場合、ある色が1個も選ばれない選び方の数は次のようになります。

| 色の個数 \(x\) | 該当する色 | 1色あたりの選び方 |
|--------|--------|--------|
| 1 | 1, 5 | \(\binom92=36\) |
| 2 | 2, 3 | \(\binom82=28\) |
| 4 | 4 | \(\binom62=15\) |

5色それぞれを計算する必要はありません。

\[
\sum_{i=1}^5\binom{10-n_i}{2}
=2\binom92+2\binom82+\binom62
=143
\]

と、3種類の計算だけで済みます。

よって、

\[
E_2=5-\frac{143}{45}
=\frac{82}{45}
\]

です。

### 一般化する

\(a_x\) を「ちょうど \(x\) 個存在する色の種類数」と定義します。

先ほどの例では、

\[
a_1=2,\quad a_2=2,\quad a_4=1
\]

で、それ以外は \(0\) です。

すると期待値の式は

\[
\boxed{
E_K=C-\frac{\displaystyle\sum_{x=1}^{N}a_x\binom{N-x}{K}}{\binom NK}
}
\]

に書き換えられます。

ここで自然に生まれる疑問は、**\(a_x\ne0\) となる \(x\) は、最大で何種類あるのか？** というものです。

これが本問の決定的な着眼点になります。

## 4\. 出現回数の種類は \(O(\sqrt N)\) 個しかない

\(a_x>0\) となる相異なる値を

\[
x_1<x_2<\cdots<x_M
\]

とします。

つまり、キャンディの個数として実際に登場する値が \(M\) 種類あるということです。

各 \(x_j\) について、少なくとも1色は \(x_j\) 個のキャンディを持っているので、

\[
N=\sum_{x=1}^{N}x a_x
\ge x_1+x_2+\cdots+x_M
\]

です。

さらに、\(x_1,\ldots,x_M\) は相異なる正整数なので、

\[
x_1\ge1,\quad x_2\ge2,\quad\ldots,\quad x_M\ge M
\]

が成り立ちます。

したがって、

\[
N\ge 1+2+\cdots+M
=\frac{M(M+1)}2
\]

となります。

これを \(M\) について解くと、

\[
\boxed{M=O(\sqrt N)}
\]

が得られます。

たとえば \(N=10\) なら、出現回数の種類は最大3種類です。もし4種類あるなら、最低でも

\[
1+2+3+4=10
\]

個が必要なので、実は4種類まで可能です。正確には \(N=10\) の最大は4種類であり、先ほどの例の3種類はその範囲内です。

一般に \(N=50000\) でも、出現回数の種類は最大315種類しかありません。

つまり、元の色が数万種類存在しても、同じ出現回数をまとめれば、1つの \(K\) につき高々315項を調べるだけで済みます。

これで全体 \(O(N\sqrt N)\) の解法が完成します。

※ 上の \(N=10\) の説明にある「最大3種類」は誤記で、正しくは最大4種類です。\(1+2+3+4=10\) なので、4種類は実現できます。

## 5\. 二項係数を高速に計算する

ここまでで、各 \(K\) について計算すべき項数が \(O(\sqrt N)\) になるとわかりました。

ただし、各項の二項係数を毎回 \(O(N)\) 時間で計算していては間に合いません。

法 \(p=998244353\) のもとで階乗と逆階乗を前計算します。

\[
\mathrm{fact}[n]=n!\pmod p
\]

\[
\mathrm{ifact}[n]=(n!)^{-1}\pmod p
\]

すると、

\[
\binom nk
=\mathrm{fact}[n]\,
\mathrm{ifact}[k]\,
\mathrm{ifact}[n-k]
\pmod p
\]

によって、二項係数を \(O(1)\) 時間で計算できます。

また、

\[
\binom NK^{-1}
=\mathrm{fact}[K]\,
\mathrm{fact}[N-K]\,
\mathrm{ifact}[N]
\pmod p
\]

なので、求める期待値

\[
E_K=C-\frac{\sum_x a_x\binom{N-x}{K}}{\binom NK}
\]

も \(O(\sqrt N)\) 時間で計算できます。

なお \(N<998244353\) なので、必要な階乗・二項係数の逆元は必ず存在します。

### アルゴリズム全体

1. 色 \(c_i\) をソートして、各色の出現回数を求める。
2. 各 \(x\) について、出現回数が \(x\) である色の個数 \(a_x\) を求める。
3. \(a_x>0\) の \(x\) だけを列挙する。
4. 階乗と逆階乗を前計算する。
5. \(K=1,\ldots,N\) について期待値の式を計算する。

計算量は

\[
O(N\log N+N\sqrt N)=\boxed{O(N\sqrt N)}
\]

で、空間計算量は \(O(N)\) です。

## 6\. C++23 実装

```cpp

#include <bits/stdc++.h>
using namespace std;

using ll = long long;
constexpr ll MOD = 998244353;

ll modpow(ll a, ll e) {
    ll res = 1;
    while (e > 0) {
        if (e & 1) res = res * a % MOD;
        a = a * a % MOD;
        e >>= 1;
    }
    return res;
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int N;
    cin >> N;

    vector<int> c(N);
    for (auto& x : c) cin >> x;
    sort(c.begin(), c.end());

    // a[x] = x 個出現する色の種類数
    vector<int> a(N + 1);
    int C = 0;

    for (int i = 0; i < N;) {
        int j = i + 1;
        while (j < N && c[j] == c[i]) ++j;

        ++a[j - i];
        ++C;
        i = j;
    }

    // 実際に存在する出現回数だけ保持
    vector<pair<int, int>> active;
    for (int x = 1; x <= N; ++x) {
        if (a[x] > 0) {
            active.emplace_back(x, a[x]);
        }
    }

    // 階乗・逆階乗
    vector<ll> fact(N + 1), ifact(N + 1);

    fact[0] = 1;
    for (int i = 1; i <= N; ++i) {
        fact[i] = fact[i - 1] * i % MOD;
    }

    ifact[N] = modpow(fact[N], MOD - 2);
    for (int i = N; i >= 1; --i) {
        ifact[i - 1] = ifact[i] * i % MOD;
    }

    for (int K = 1; K <= N; ++K) {
        // sum_x a[x] * C(N-x, K)
        ll missing = 0;

        for (auto [x, cnt] : active) {
            if (N - x < K) continue;

            ll ways = fact[N - x] * ifact[K] % MOD
                      * ifact[N - x - K] % MOD;

            missing = (missing + cnt * ways) % MOD;
        }

        // 1 / C(N, K)
        ll inv_total = fact[K] * fact[N - K] % MOD
                       * ifact[N] % MOD;

        ll ans = (C - missing * inv_total % MOD + MOD) % MOD;

        cout << ans << '\n';
    }
}
```

この実装は問題の2つのサンプルに一致し、小規模なランダムケース100件について全列挙との照合も通過しています。

## 7\. この問題から学ぶ重要な典型

本問には、難しい問題でも頻出する3つの重要な考え方が含まれています。

### 典型① 期待値の線形性による寄与の分解

「選ばれた集合に含まれる異なる色の数」は、集合全体を見ないとわからない量です。

しかし、それぞれの色が登場したかどうかを表す \(0/1\) 変数の和として書けば、各色を個別に扱えます。

一般に、ある結果のスコアが

\[
X=\sum_i X_i
\]

と表現できれば、

\[
E[X]=\sum_i E[X_i]
\]

が成立します。

特に \(X_i\) が条件の成立を表す指示変数なら、

\[
E[X_i]=P(X_i=1)
\]

です。

この考え方は、次のような問題で候補になります。

- ランダムに要素を選んだとき、登場する種類数の期待値
- ランダムに辺を選んだとき、特定の条件を満たす頂点数の期待値
- ランダムな操作後に、少なくとも1回影響を受ける対象の個数の期待値

重要なのは、**数えたい対象を「それぞれが条件を満たしたか」という指示変数の和に分解できないか**と考えることです。

本問ではさらに、少なくとも1回登場する確率よりも、1回も登場しない余事象の確率のほうが簡単に計算できました。

この「指示変数への分解」と「余事象」はセットで使うことが多いです。

### 典型② 寄与が同じ要素をまとめる

和

\[
\sum_{i=1}^{C}f(n_i)
\]

を計算するとき、\(f\) が \(n_i\) の値だけに依存するなら、同じ \(n_i\) を持つ要素をまとめられます。

\[
\sum_{i=1}^{C}f(n_i)
=\sum_x a_x f(x)
\]

この変形自体は単純ですが、競技プログラミングでは非常に重要です。

特に、複数のクエリに対して同じ要素集合を走査しているときは、

「各要素のどの情報が実際に答えに影響しているのか？」

と考える価値があります。

たとえば、要素の識別子ではなく次数、出現回数、距離、重みなどの値だけが影響するなら、その値ごとに集約できる可能性があります。

ただし、まとめただけでは計算量が改善するとは限りません。**集約後の異なる値の個数が少ないこと**が必要です。

本問は、次の典型によってその条件を保証できる点が巧妙です。

### 典型③ 相異なる正整数の総和による \(O(\sqrt N)\) の評価

本問で最も汎用性の高い観察です。

相異なる正整数の集合 \(S\) があり、

\[
\sum_{x\in S}x\le N
\]

なら、

\[
|S|=O(\sqrt N)
\]

です。

これは、\(|S|=M\) とすると、和の最小値が

\[
1+2+\cdots+M=\Theta(M^2)
\]

になることから従います。

この性質が使えるのは、「異なる値を1つずつ採用するだけでも、その値に比例したコストが必要」という状況です。

たとえば、グラフの各頂点の次数を考えます。

無向グラフの次数の総和は \(2E\) です。したがって、正の次数として実際に登場する値の種類数は

\[
O(\sqrt E)
\]

に抑えられます。

これは本問における

\[
\sum_x xa_x=N
\]

と同じ構造です。

**どんなときにこの性質を疑うか？**

「値の範囲は大きいが、各値の存在に一定の資源が必要で、その資源の総量は小さい」という条件を見たときです。

また、よく知られる平方分割の考え方とも関連があります。

たとえば、頻度 \(x\) に対して閾値 \(B\) を設ければ、\(x>B\) となる頻度を持つ色は高々 \(N/B\) 種類です。\(B\approx\sqrt N\) とすれば、高頻度の色は少数になります。

ただし本問では、頻度を大小に分割する必要すらありません。**出現する頻度の値そのものが \(O(\sqrt N)\) 種類しかない**ため、全種類をそのまま走査できます。

この違いを理解しておくと、平方分割が必要な問題と、疎な値だけを列挙すればよい問題を見分けやすくなります。

## 8\. 復習で定着させたいこと

- **種類数の期待値**は、各種類の登場を表す指示変数の和として考える。
- 「少なくとも1個選ばれる」は、余事象である「1個も選ばれない」のほうが数えやすいことがある。
- 同じ寄与を持つ要素をまとめたら、集約後の異なる値が何種類あるかを評価する。
- 相異なる正整数の総和が \(N\) 以下なら、その個数は \(O(\sqrt N)\)。
- 数式の各項が \(O(1)\) で計算できるように、階乗・逆階乗などの前計算を利用する。

本問では、期待値の式を立てることも重要ですが、最終的な高速化を生むのは **「色の種類数は多くても、出現回数の種類数は少ない」** という構造の発見です。

この種の「総量の制約から、異なる状態の個数が少ないことを示す」考察は、難関コンテストでもぜひ候補に挙げたい典型です。
